子どもたちに地学の面白さを届けるAI同定プロジェクト

公開の目的

山形県寒河江市上野の寒河江川河床（後期中新世・本郷層）は、凝灰質礫岩が露出し、豊富な軟体動物化石が観察できる貴重な地学学習の場です。

現地で化石採集をしていた際、偶然居合わせた子どもたちに化石の種を教えたことをきっかけに、地学への深い興味を持ってもらえることを実感しました。化石の「種」をその場で判別できる仕組みを提供し、単なる採集にとどまらず、日本および世界中の子どもたちが地学の面白さに触れるきっかけを作ることを目指しています。

学習対象となる主な化石

AIモデルの精度向上に向け、多様な状態の化石画像を多角的に撮影して学習データを作成しています。

ホタテガイ類（優占種）
Mizuhopecten matumoriensis (Nakamura)
本郷層 産出化石
割れ・礫付着個体の学習データ

システム構成

Scratch

fossil博士1号

操作の直感性と親しみやすさを重視。破損の少ない個体を対象に、小学生でもロジックを理解しやすいフローチャート形式で判定する同定システムです。

Teachable Machine

fossil博士2号

優占種 Mizuhopecten matumoriensis の約4,000枚を含む、合計8,000枚規模の画像データでディープラーニング。割れや未クリーニングで礫が付着した実用状態の化石でも高精度に同定します。

研究・開発の流れ

  • 小学1〜2年生
    浜辺でオウムガイの化石を拾い、博物館で鑑定を受けた体験から化石への興味が芽生える。
  • 小学5年生
    プログラミング教室に通い始め、Scratchを中心に開発スキルを磨く。
  • 中学3年生
    寒河江川での野外体験を原点に「ディープラーニングとプログラミングを活用した化石同定システムの研究開発」を発表。
  • 現在（高校1年生）
    GitHub Pagesでの一般公開およびシステムモデルの更なる精度向上を推進中。
